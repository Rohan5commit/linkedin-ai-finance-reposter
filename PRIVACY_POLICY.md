# Privacy Policy

This LinkedIn automation app (`linkedin-ai-finance-reposter`) only posts public news summaries to the account that authorizes it.

## Data usage

- Uses LinkedIn OAuth access token provided by the account owner.
- Uses LinkedIn Person URN provided by the account owner.
- Reads public news feeds (RSS/API) to generate post content.
- Does not collect, sell, or share personal user data.

## Storage

- Tokens are stored only as GitHub Actions secrets by the repository owner.
- No secrets are committed to the repository.

For questions, open an issue in this repository.
